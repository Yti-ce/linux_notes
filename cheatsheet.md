# Linux command cheat sheet (v1)

Built from hands-on practice on Ubuntu Server 26.04.1 (Day 2: filesystem and paths). Updated as the plan goes on.

## Filesystem hierarchy (FHS)

```
/                  root of the whole tree
├── etc            system configuration (e.g. /etc/netplan, /etc/ssh/sshd_config)
├── var            variable data; logs live in /var/log
├── home           home directories of normal users (/home/admin123 = ~)
├── root           home of the root user (drwx------, only root can enter)
├── tmp            temporary files, writable by everyone
├── usr            programs and libraries (/bin -> usr/bin)
├── boot           kernel and boot files
├── dev            devices exposed as files (disks, NICs)
└── proc, sys      virtual files generated by the kernel in memory (size 0)
```

Useful logs in `/var/log`:

| File | Content |
|---|---|
| `syslog` | general system log |
| `auth.log` | logins, SSH, `sudo` |
| `kern.log` | kernel messages |
| `dpkg.log`, `apt/` | package installs |
| `wtmp`, `btmp` | binary login records, read with `last` / `sudo lastb` |

Rotated logs: `x.log` is newest, then `x.log.1`, `x.log.2`, ...

## Reading the prompt and `ls -l`

```
admin123@admin:/etc$ cd ..
└ user ┘ └host┘└cwd┘  └ what I typed ┘      $ = normal user, # = root
```

```
drwxr-xr-x 109 root root 4096 Oct 29 07:32 etc
type+perms links owner group size  mtime   name
```

First character: `d` directory, `-` regular file, `l` symbolic link.

## Paths

| Path | Meaning |
|---|---|
| `/etc/ssh` | **absolute**: starts with `/`, same result from anywhere |
| `ssh` | **relative**: resolved as *current dir* + `/ssh` |
| `.` | current directory |
| `..` | parent directory |
| `~` | my home directory |
| `-` (with `cd`) | previous directory |

Example: in `/` `cd etc` works, in `~` `cd etc` fails (`/home/admin123/etc` does not exist), `cd /etc` works everywhere.

## Commands

| Command | What it does |
|---|---|
| `pwd` | print current directory |
| `cd /var/log` / `cd ..` / `cd ~` / `cd -` | change directory (absolute / up / home / back) |
| `ls` | list current directory (columns, alphabetical, top-to-bottom) |
| `ls -l` | long format: type, permissions, owner, size, time |
| `ls -a` / `ls -la ~` | include hidden dotfiles (`.bashrc`, `.ssh`) |
| `ls -1` | one name per line |
| `ls -F` | append `/` to directories |
| `cat file` | print file contents |
| `tail -n 5 file` | last 5 lines of a file |
| `mkdir lab` | create a directory |
| `touch a.txt` | create an empty file |
| `echo "text" > b.txt` | write text into a file (**overwrites**) |
| `cp b.txt c.txt` | copy file (source, then destination) |
| `cp b.txt docs/` | copy into a directory, keep the name |
| `mv c.txt notes.txt` | rename |
| `mv notes.txt docs/` | move into a directory (original is gone) |
| `rm -i a.txt` | delete a file, ask first |
| `rm -ri docs` | delete a directory and its contents, ask for each item |
| `find ~ -name "*.txt"` | search recursively by name (`*` = any characters) |
| `find /etc -name "sshd_config" 2>/dev/null` | same, hide `Permission denied` errors |
| `cat /etc/os-release` | distribution and version |
| `last -n 3` | recent logins |
| `sudo cmd` | run one command as root |
| `ls -l /var/log \| grep ^d \| wc -l` | count directories (pipe preview) |

## Gotchas

- No recycle bin: `rm` is permanent. Use `-i` while learning; never run `rm -rf` on `/` or a path you are not sure about.
- Many commands print nothing on success (`mkdir`, `cp`, `mv`). Silence = OK.
- Error format: `program: command: object: reason`. `No such file or directory` usually means a wrong path or wrong current directory.
- `>` overwrites, `>>` appends.

## Users and permissions (Day 3)

| Command | What it does |
|---|---|
| `id` / `id alice` | user id, primary group, all groups |
| `sudo useradd -m -s /bin/bash alice` | create user with home dir and bash |
| `sudo groupadd dev` | create a group |
| `sudo usermod -aG dev alice` | add user to group (**always `-a`**) |
| `sudo -u alice cmd` | run a command as another user |
| `chmod o-r f` / `chmod g+w f` | remove / add one permission (`u` `g` `o`) |
| `chmod 750 f` | numeric: r=4 w=2 x=1, one digit per set |
| `sudo chown root:dev /srv/dev` | change owner and group |
| `ls -ld dir` | permissions of the directory itself |
| `umask` / `umask 077` | show / set default mask (file = 666 − umask) |

Common modes: `644` file, `600` private file, `755` directory/script, `750` home dir, `770` group-shared dir.

## Package management with apt (Day 4)

| Command | What it does |
|---|---|
| `sudo apt update` | refresh the package index (installs nothing) |
| `apt list --upgradable` | packages with newer versions |
| `apt search tree` | search package names and descriptions |
| `apt show tree` | package details: version, `Installed-Size`, description |
| `sudo apt install tree` | download and install a package |
| `sudo apt remove tree` | uninstall, **keep** config files |
| `sudo apt purge tree` | uninstall **and** delete config files |
| `apt list --installed tree` | is it installed? (no output = not installed) |

Long output opens in the `less` pager: `q` quit, Space next page, arrows scroll.

## Viewing text, redirection and pipes (Day 5)

| Command | What it does |
|---|---|
| `cat f` | print the whole file (short files) |
| `head -n 5 f` / `tail -n 5 f` | first / last 5 lines |
| `less f` | page through a long file: Space next page, `q` quit |
| `echo "text"` | print the **text itself** (not a file's contents) |
| `cmd > f` | write output to a file, **overwrite** |
| `cmd >> f` | write output to a file, **append** |
| `cmd1 \| cmd2` | pipe: output of `cmd1` becomes input of `cmd2` |
| `grep word` | keep only lines containing `word` (case-sensitive) |
| `grep -v word` | keep only lines **not** containing `word` |
| `wc -l` | count lines |
| `sort` / `sort -r` | sort a–z / reverse |

Examples practiced:

```bash
grep bash /etc/passwd | wc -l              # users who can log in with bash (5)
grep -v nologin /etc/passwd | wc -l        # accounts without nologin (7)
head -n 2 /etc/passwd | tail -n 1          # only line 2
grep CRON /var/log/syslog | tail -n 3      # last 3 cron runs
ls /etc | sort > ~/etc-sorted.txt          # save a result
echo "checked on Nov 3" >> ~/login-users.txt   # add one line
```

`/etc/passwd` format: `name:x:UID:GID:comment:home:shell`. Shell `/usr/sbin/nologin` = service account that cannot log in.

Mistakes I made: typed `touch` for `tail`; used `echo /etc/passwd | grep bash` (prints the words "/etc/passwd", so grep finds nothing — use `cat` or `grep bash /etc/passwd`); used `>>` to save a fresh result (run twice → duplicates; use `>`).
